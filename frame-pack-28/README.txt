SPACEBOOTH — 28 KHUNG TRANG TRÍ

CÁCH GHÉP VÀO PROJECT
1. Chép thư mục public/frames/spacebooth vào frontend/public/frames/spacebooth.
2. Chép src/utils/frameCatalog.js và photoStrip.js vào frontend/src/utils.
3. Bộ chọn hiện tại dùng STRIP_TEMPLATES sẽ tự có đủ mẫu, không cần sửa CaptureScreen.jsx.
4. Chạy npm run build trong frontend, sau đó npm run dev.

THÀNH PHẦN
- 28 PNG nền trong suốt. frame-01 là Trăng hoa đã chốt.
- Hai file JavaScript hoàn chỉnh để ghép khung vào dải ảnh.
- preview-28-frames.jpg: xem toàn bộ ảnh khung.
- preview-2-photos.jpg: xem các khung ghép thử với hai ảnh minh họa.

Hai mẫu Dải phim / Rạp chiếu giữ trong code, nên bộ chọn có tổng 30 lựa chọn.
Bộ ghép hỗ trợ 1–5 ảnh, giữ tỷ lệ ảnh chụp, vạch ngăn theo tông từng khung.
Dải ảnh dùng khung trang trí xuất PNG rộng 1600 px; chiều cao theo ảnh được chọn.
Ảnh nguồn không đổi kích thước trong ZIP. Dùng bộ ghép để giữ tỷ lệ góc và họa tiết.

Ảnh được phục dựng từ mẫu nhỏ nên chi tiết nhỏ có thể khác ảnh gốc.
Phần tiếp theo là sticker.
